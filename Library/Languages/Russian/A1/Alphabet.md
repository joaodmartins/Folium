# Russian Alphabet

An introduction to the Cyrillic alphabet used in Russian.

## Overview

Russian is written in the Cyrillic script, which has 33 letters. Many letters
look familiar, but some of them sound different from their Latin lookalikes.

Some of the first letters:

| Letter | Name | Sound |
|--------|------|-------|
| А а | a | like *a* in "father" |
| Б б | be | like *b* in "book" |
| В в | ve | like *v* in "very" |
| Г г | ge | like *g* in "go" |
| Д д | de | like *d* in "day" |

## Study tips

- Learn the letters that look like Latin ones but sound different (В, Н, Р, С).
- Practise by reading road signs and shop names.
- Write each letter by hand a few times.
- Revise a few letters every day instead of all of them at once.
